# 文字拼圖 Chinese Jigsaw Puzzle

> 輸入 1～20 個中文字，自動變成一幅帶卡榫的拼圖，用滑鼠或手指拼回來

- **網址：** https://wangchiapin.github.io/chinesejigsaw/
- **Firebase 專案：** memorma-24dab（只用在排行榜，集合 `jigsaw_boards`；與 Memorama、收納小達人等共用同一個專案）
- **登入方式：** 匿名登入（不用註冊，只在存成績時輸入名字）
- **狀態：** 使用中
- **遊戲名稱：** 中文「文字拼圖」／英文「Chinese Jigsaw Puzzle」／西班牙文「Rompecabezas de chino」

## 玩法
- 輸入想拼的文字（最多 20 字，空白會被忽略；留空就用預設「拼圖遊戲」），選拼圖大小：8×8、10×10、12×12、15×15，再選難度，按「開始新遊戲」。
- 文字會被切成帶卡榫的拼圖片，散在「未使用的拼圖池」（電腦在左邊，手機直放在下方）。
- 拖曳拼圖到桌上；相鄰且對的兩片靠近會自動吸在一起，拼好的小塊可以整塊拖動；桌上可以同時拼好幾個不同的地方。
- 全部拼好會顯示完成時間和移動次數，可以存到排行榜，也可以「再玩一次」或「看看成品」。
- 一打開頁面會先排好一副預設拼圖，停在「▶ 開始」按鈕前；按了才開始計時，並記成一局（後台「遊玩紀錄」用）。按「開始新遊戲」則直接開始。
- 已經拼了一半時按「開始新遊戲」會先確認，避免誤放棄進度。
- 上方有計時和移動次數（拿起、放下算一次；進階難度轉一下也算一次）。

## 難度
- **輕鬆**：拼圖片不會旋轉。
- **進階**：每片一開始的方向是亂的，要先轉到正確方向才能接合（一次轉 90 度）。
  - 電腦：按 **R** 鍵（Shift＋R 反方向）或滑鼠**滾輪**，或在片上**雙擊**（順時針 90 度）；拖著片子時也可以轉，拼圖池裡的片用 R 鍵或雙擊轉。
  - 手機：**點一下**拼圖片就轉；手上拖著片子時，另一隻手指點一下螢幕也能轉。
  - 接好的整塊會一起轉；全部接好後如果整張是歪的，會自動轉正。

## 輔助按鈕
- **整理拼圖池**：把池中的碎片重新排整齊。
- **邊角優先**：邊緣和角落的拼圖排在前面。
- **完成圖**：看完成後的樣子。
- **提示框**：在桌上顯示拼圖範圍。
- **🎵**：背景音樂（程式合成的水滴聲和風聲，預設開啟）；**🔊**：接合音效。瀏覽器規定要先點一下畫面，音樂才會開始。
- **❓ 說明**：遊戲內的操作、分級說明。
- 池子可用滾輪或拖曳空白處捲動。

## 手機版
- 螢幕寬度 700px 以下（或橫放的手機）自動切換成手機版；網址加 `?m=1` 可強制手機版、`?m=0` 強制電腦版。
- 上方只有遊戲名稱、計時和移動次數；功能鍵在下方：新遊戲、拼圖池、完成圖、整理、更多。
- 拼圖池變成下方的橫向托盤（左右滑動，點標題收合）；手機橫放時拼圖池在左邊。
- 桌面可以移動和縮放：單指拖空白處＝移動畫面，兩指＝放大縮小，右上「回到全貌」回到整張桌面；拖著片子靠近邊緣時畫面會自動跟著移動。

## 排行榜
- 依「拼圖大小」和「難度」分開排：先比完成時間，時間一樣比移動次數；每台裝置每個榜只留最好的成績；不同字數、不同文字放在同一個榜。
- 資料在 Firestore `jigsaw_boards/{榜名}/entries/{uid}`：榜名 `8`、`10`、`12`、`15` ＝ 輕鬆；`8r`、`10r`、`12r`、`15r` ＝ 進階。
- 欄位：`name`、`secs`、`moves`、`text`、`rank`（`(99999 − secs) × 10000 + (9999 − moves)`）、`script`、`lang`、`updatedAt`。
- Firebase 規則（memorama-24dab）要有 `jigsaw_boards` 這一段，包含上面八個榜名，否則存成績會顯示「儲存失敗」（遊戲本身不受影響）。

## 設定（記在玩家瀏覽器）
- 字體：繁體／简体
- 介面語言：中文＋Español／中文＋English／只有中文
- 拼音／注音：Pinyin、ㄅㄆㄇ、兩者、不顯示（顯示在每個字上方，從下一局開始）
- 接合吸力：弱（要放很準）／中／強（靠近就吸住）
- 字體、語言、拼音／注音用 `localStorage` 的 `hanziGames.settings`，與其他漢字遊戲共用；吸力、音樂、音效、難度另存在 `jigsaw_settings_v1`。

## 台灣讀音
- 拼音與注音用 [pinyin-pro](https://github.com/zh-lm/pinyin-pro)（由 jsDelivr 載入，需要網路），再套用「台灣讀音例外表」（如：還是、什麼、垃圾、星期、休息…），連接詞「和」念 hàn。
- 這份例外表與「跑吧！漢字」句子管理工具、台灣生存日記共用；發現讀錯的詞，加到 `index.html` 裡的 `TW_PINYIN` 即可。
- 載入失敗時仍可玩，只是不顯示拼音／注音。

## 技術
- 單一檔案 `index.html`（無需建置），圖片、卡榫與音效全部用 Canvas／Web Audio 即時產生；排行榜用 Firebase（匿名登入＋Firestore）。
- 部署：GitHub Pages。
- 華語老師分享區（`cadadiaunosminutos-share-zone`）的遊戲卡片 id 是 `jigsaw`，後台開關是 `game-jigsaw`。
