# 文字拼圖 Jigsaw Puzzle

> 輸入 1～20 個中文字，自動變成一幅可以拼的文字拼圖

- **網址：** https://wangchiapin.github.io/chinesejigsaw/
- **Firebase 專案：** 不使用 Firebase
- **登入方式：** —
- **狀態：** 使用中

## 玩法
- 上方輸入想拼的文字（最多 20 字，空白會被忽略；留空就用預設「拼圖遊戲」），選拼圖數量：10×10、12×12、15×15。
- 按「開始新遊戲」，文字會被切成帶卡榫的拼圖片，散在右側的「未使用的拼圖池」。
- 拖曳拼圖到桌上；相鄰且對的兩片靠近會自動吸在一起，拼好的小塊可以整塊拖動。
- 全部拼好會顯示完成時間，可以「再玩一次」或「看看成品」。
- 已經拼了一半時按「開始新遊戲」會先確認，避免誤放棄進度。

## 輔助按鈕
- **整理拼圖池**：把池中的碎片重新排整齊。
- **邊角優先**：邊緣和角落的拼圖排在前面。
- **完成圖**：看完成後的樣子。
- **提示框**：在桌上顯示拼圖範圍。
- **🔊**：開關接合音效。
- 池子可用滾輪或拖曳空白處捲動。

## 設定（記在玩家瀏覽器）
- 字體：繁體／简体
- 介面語言：中文＋Español／中文＋English／只有中文
- 拼音／注音：Pinyin、ㄅㄆㄇ、兩者、不顯示（顯示在每個字上方）
- 接合吸力：弱（要放很準）／中／強（靠近就吸住）
- 設定用 `localStorage` 的 `hanziGames.settings`，與其他漢字遊戲共用；吸力另存。

## 台灣讀音
- 拼音與注音用 [pinyin-pro](https://github.com/zh-lm/pinyin-pro)（由 jsDelivr 載入，需要網路），再套用「台灣讀音例外表」（如：還是、什麼、垃圾、星期、休息…），連接詞「和」念 hàn。
- 這份例外表與「跑吧！漢字」句子管理工具、台灣生存日記共用；發現讀錯的詞，加到 `index.html` 裡的 `TW_PINYIN` 即可。
- 載入失敗時仍可玩，只是不顯示拼音／注音。
